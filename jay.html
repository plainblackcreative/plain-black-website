The system

How a stranger becomes a client

Most of what I do runs through a handful of tools I've built for myself. Here's the chain, start to finish.

  1. Find

    Lead Scout

    A local tool I give a service and a town, like electrician in Papamoa. It searches Google Places, then checks each business's website in a headless browser: read-only, one request a second, robots.txt honoured, nothing clicked or submitted.

    A fault only counts when a second, later check agrees. What comes out is a one-page brief of real problems, like a tap-to-call button that dials a different number from the one on the page, or a homepage wider than a phone screen.

  2. Build

    The concept site

    One command, /site-demo, with a written floor every build has to clear:

    • A live hero effect (WebGL or canvas) made from their own photos
    • Scroll set pieces, spread over pages so it never gets busy
    • An enquiry builder and tap-to-call
    • Their real reviews, word for word
    • Every page and link from their current site, so nothing goes missing

    Each build records its signature effects, and the next build isn't allowed to repeat them. No made-up stats, reviews, prices or awards, ever.

  3. Send

    Tracked preview links

    One command publishes the page to its own address, hidden from search engines. Every link carries the person's name, so I know who opened it. A real open is 15 seconds on the page with a scroll or a click, and that sends me an email. A quick bounce doesn't count.

  4. Sell

    The sales board

    A private board my sales partner and I share. Every concept and lead has a card that moves through To build, Fresh, Sent, Opened, Talking, Proposal, Won or Lost. When someone opens their link, their card moves to Opened by itself. When my partner adds a lead, I get an email with the command to build their concept.

  5. Run

    The client's site and dashboard

    The dashboards are plain HTML, CSS and JavaScript with no build step, on Cloudflare: Pages to serve them, Functions and Workers for the logic, D1 and KV for data. Each client's dashboard sits behind its own login. The form handler and the morning jobs are shared, so a fix for one client reaches all of them.

  6. Remember

    JB Brain

    A Node server on my Mac with its own database. Emails, notes and screenshots land in one queue and get filed against the right client. Every client's record and open tasks live there, and each record is kept in git.

House rules

What every build sticks to

  • Clients own their data

    New clients get their own Google Analytics and Search Console, with me as an admin. Nobody gets locked out of their own numbers.

  • Nothing invented

    A quote, review, statistic or "since 19XX" goes on a page only if I can link where it came from.

  • Only the public site goes live

    Research, notes and config stay in private repos. A deploy publishes the folder the pages load, never the whole project.

  • One type scale

    Everything new uses the same set of text sizes, built on Apple's iPhone defaults. Nothing under 13px.

  • A tap is an enquiry

    A tap on a Call button counts like a quote form, on an ad, the website or the Google listing. Clients see every enquiry in one list.

  • AI does the typing, I make the calls

    I build with Claude Code. I set the brief, check the result and decide what ships. Every change goes through git.
